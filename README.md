## 📜 فارسی

### درباره‌ی پروژه

این وب‌سایت یک نقشه‌ی تعاملی از گسترش و تأثیر شعر پارسی در طول تاریخ و جغرافیای جهان را نمایش می‌دهد. با استفاده از این ابزار، می‌توانید سفری عبرت‌آموز به دوران‌های مختلف فرهنگ ایرانی داشته باشید و با شاعران بزرگ و آثار ماندگار آن‌ها آشنا شوید.

### ✨ ویژگی‌ها

| ویژگی | توضیح |
|-------|-------|
| 🕰️ **اسلایدر زمانی** | ناوبری آسان بین ۶ دوره‌ی تاریخی (هر دوره ۱۵۰ سال) |
| 🏙️ **شهرهای مهم** | شهرهای برجسته با قابلیت تعامل و انتخاب |
| 📚 **اطلاعات شاعران** | بیوگرافی و آثار مهم هر شاعر |
| 🗺️ **نقشه‌ی پویا** | مرزهای تاریخی به صورت دینامیک نمایش داده می‌شوند |
| 🎨 **طراحی واکنش‌گرا** | تجربه‌ی کاربری بهینه در دستگاه‌های مختلف |

## 🇬🇧 English

### About the Project

This website provides an interactive map showcasing the influence and spread of Persian poetry throughout history and geography. Navigate through different eras of Persian culture, explore important cities, and discover renowned poets and their masterpieces.

### ✨ Features

| Feature | Description |
|---------|-------------|
| 🕰️ **Time Slider** | Easy navigation between 6 historical eras (150-year intervals) |
| 🏙️ **Important Cities** | Bold, interactive city markers with detailed information |
| 📚 **Poet Information** | Biographies and major works for each poet |
| 🗺️ **Dynamic Map** | Historical borders rendered dynamically |
| 🎨 **Responsive Design** | Optimized user experience across devices |

### 📅 Historical Eras

1. **Samanid Era** (875 – 1000 CE)
2. **Ghaznavid Era** (1000 – 1150 CE)
3. **Seljuk Era** (1150 – 1300 CE)
4. **Ilkhanate Era** (1260 – 1370 CE)
5. **Timurid Era** (1370 – 1500 CE)
6. **Safavid Era** (1500 – 1736 CE)

### 🌟 Featured Poets

- **Rudaki** - Father of Persian Poetry
- **Ferdowsi** - Great Epic Poet of Iran
- **Omar Khayyam** - Mathematician & Poet
- **Attar** - Poet & Mystic
- **Rumi** - Mystical Poet
- **Saadi** - Master of Speech
- **Hafez** - The Tongue of the Unseen
- **Jami** - The Seal of Poets

### 🛠️ Tech Stack

```
📦 HTML5 / CSS3 / JavaScript
🗺️ MapLibre GL JS
🎨 Bootstrap 5 (RTL)
🔤 Vazirmatn & Lalezar Fonts
```

### 🚀 Getting Started

```bash
# Install dependencies
npm install

# Open index.html in your browser
# Or use a local server
```
